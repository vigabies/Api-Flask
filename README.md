# 📝 Tasks Flask CRUD

API de gerenciamento de tarefas desenvolvida em **Python com Flask** durante o curso de Python da **Rocketseat**.

## 🚀 Tecnologias

- Python
- Flask
- Flask-SQLAlchemy

## 📌 Funcionalidades

- Criar tarefas
- Listar tarefas
- Atualizar tarefas
- Excluir tarefas

## 🔗 Endpoints

```text
GET    /tasks       → Listar tarefas
POST   /tasks       → Criar tarefa
PUT    /tasks/<id>  → Atualizar tarefa
DELETE /tasks/<id>  → Excluir tarefa
```

## ▶️ Como executar

```bash
pip install -r requirements.txt
python app.py
```

A API estará disponível em `http://localhost:5000`.
